# ss_flopcensus --core ucore whitelist -- regs the clocked-block rule counts as
# flops that carry NO state across a clock edge.
#
# Format: one entry per line, `signal_name  # justification`.
# The justification (text after #) is MANDATORY; an entry without one FAILS.
#
# WHY THIS FILE EXISTS AND THE FSM ONE IS EMPTY.  The ucore's EU is written in
# the model's software style: blocking `=` throughout.  Its BLOCK-LOCAL WORKING
# VALUES are therefore module-scope `reg`s too, indistinguishable by
# declaration from architectural state.  Every entry below is one of those: on
# every clock it is WRITTEN BEFORE IT IS READ, by a write that dominates every
# read of it, so no value survives the edge and there is nothing for a
# save-state to carry.  Each was checked by hand against its write sites and its
# read sites (U3 platform audit).
#
# TWENTY-TWO OF THE TWENTY-FOUR ENTRIES ARE GONE, AND NOT BY HAND (U4 pass 3).
# The U3 audit booked this file as "A WORKAROUND FOR A DECLARATION, NOT A DESIGN
# DECISION -- SystemVerilog lets these be declared INSIDE the always block,
# which would remove them from the census by construction", and left it because
# the RTL was frozen.  The ENABLE-FORM refactor did the equivalent as a side
# effect: the EU's body is an `always @*` next-state function now, so `stop`,
# `ie_now`, `v1`, `v2`, `bsw`, `pv`, `nloc`, `carry`, `taken`, `bubble`,
# `retire_now`, `rep_chained`, `ea`, `rseg`, `rmmod`, `rmreg`, `rmrm`, `tk`,
# `ti`, `te`, `ts` and `tb` are COMBINATIONAL by declaration and the census
# classifies them without being told.  The EU's architectural-flop count falls
# 140 -> 118 and the whole census 223 -> 201 for that reason and no other; the
# MAP is untouched (SS_COUNT 218, SS_TAG 0x82DA, 0 UNMAPPED).
#
# The two that remain are real flops -- they are committed by the register bank
# -- and are whitelisted on their old, unchanged justifications.
#
# Do NOT add an entry here to silence a genuine save-state gap.  A reg that
# carries live machine state across a clock edge MUST be mapped.

# --- v30u_eu.sv: the clocked block's own working values --------------------
tsel         # F29's live tmp: full-case write v30u_eu_row.svh:89-92, read at 95-97

# --- DERIVED (a SECOND class, and it is NOT the one above) -----------------
#
# ⚠ EVERY ENTRY ABOVE IS ADMITTED ON "written before read on every clock, so no
# value survives the edge".  AN ENTRY BELOW *DOES* SURVIVE THE EDGE.  It is
# admitted on a different, narrower ground and the ground is stated per entry:
#
#   the register is a PURE FUNCTION of registers that ARE SSA-mapped, and it is
#   recomputed from the SAME next-state expression under the SAME commit
#   condition as those registers -- so a save-state restore that writes the
#   mapped addresses reconstructs it ON THAT VERY EDGE, and mapping it would
#   give one fact two sources of truth (and let a stream carry a `dec_q` that
#   disagrees with the `upc_*` beside it, which the RTL cannot produce).
#
# The bar for this class is that the derivation is CHECKABLE BY EYE against the
# commit block, in one place, and that the entry names that place.  Do NOT put
# a register here because it is inconvenient to map.
dec_q        # DERIVED: {dec_valid,dec_bank} = ucdecode[dec_addr_next], and `dec_addr_next` (v30u_eu.sv, immediately above THE COMMIT) is character for character the commit's own upc_page/upc_opc/upc_loc selection. L1, docs/notes/adcone_l1_prereg_2026-08-13.md §1.
s1q          # DERIVED: the ce/ce_half PHASE SPLIT's shadow (WAVE 4, 2026-09-08 -- WAVE 2's, widened from 495 to 778 bits by the CUT SET (A-1), and to 779 by WAVE 19's ARM-B, whose ONE added bit `qripe_pop` is the 1BL-lead select `q_pop && q_ripe && !q_flush` -- a WIDENING OF THIS ENTRY, NOT A NEW ONE). It is STAGE 1 of the next-state cone -- a pure function of `ce`-committed registers, the EU's own and the EIGHT REGISTERED BIU views the wire cone reads (eu_access_active / eu_opr_free / eu_rd_done_n / eu_slot_busy / eu_wr_done_n / eu_wr_eval / q_byte / q_ripe -- the eighth arrived with ARM-B and is `poppable != 4'd0` at v30u_biu.sv:848 over r_grn_ttl / r_q_cnt / r_grn_n, whose addresses are SSA_B_GRN_TTL / SSA_B_Q_CNT / SSA_B_GRN_N at v30u_biu.sv:2858-2860), ALL of which are SSA-mapped on their own side -- captured on `ce_half` and consumed by STAGE 2 on `ce`. The place it is CHECKABLE BY EYE is THE CUT in v30u_eu.sv: the pack `s1_bus = { ... }` and the unpack `{ ... } = s1q` carry CHARACTER-IDENTICAL concatenations, and `sw/phase_split_lint.py` FAILS if they ever differ or if their summed declared widths stop equalling S1W; `sw/cutset_lint.py` FAILS if stage 2 can name a pre-cut wire at all. RECONSTRUCTED ON THAT VERY EDGE, and the edge is named: its commit condition is `(ss_we || srst || ce_half)`, so a restore re-derives it on the A2 RESUME-DRAIN clock -- the clock the resume contract already requires, where `ss_we_q` is still high and every stream word has landed -- from the FULLY RESTORED register file. `srst` is in the condition for a second, separate reason: RESET is asserted at the head of every run, so the shadow is current at a run's FIRST `ce` whether or not a `CE_HALF` preceded it. AND THE DERIVATION IS ASSERTED, NOT ASSUMED: `ifndef SYNTHESIS`, `s1q !== s1_bus` at any `ce` is a `$fatal`, over every golden case and all 4 x 400,000 chain_lfsr clocks. docs/notes/phase_split_cutset_prereg_2026-09-08.md, RULING 2's option (i) -- NO RULE IS WIDENED.
